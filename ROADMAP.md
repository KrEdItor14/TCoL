### Главный блокер прямо сейчас

Release-кандидат **не подтверждён**:
- в Android outputs обнаружен только `app-debug-androidTest.apk`, установочный release APK/AAB не найден
- web-версия `3.7.4` расходится с Android `versionCode 1` / `versionName "1.0"`
- нет release signing / keystore

Для AI необходимо развернуть и проверить обновлённый worker, который принимает только личный API-ключ пользователя. Общий серверный ключ удалён из клиента; бесплатный режим отключён.

**Цель Stage 3.5:** довести техническую готовность релизного билда до ~60–70%, после чего открывать Stage 4.

## Этап 4. Публикация на RuStore — после RC

**Цель:** первый публичный релиз в каталоге RuStore.  
**Входное условие:** Stage 3.5 закрыт (есть подписанный RC и device smoke).

### 4.0. AI proxy и пользовательский ключ (обязательно до upload)

Локальный клиент и `js/worker.js` больше не используют общий `PROXY_SECRET`, серверный API-ключ или бесплатный тариф. Worker пересылает запрос только при наличии личного Tooken API-ключа; ключ не записывается worker-кодом и не сохраняется в журнале приложения. Пользователь оплачивает запросы по условиям своего провайдера.

- [ ] Развернуть обновлённый worker и проверить запрос с валидным личным ключом
- [ ] Проверить, что запрос без личного ключа отклоняется и worker не использует серверный ключ
- [ ] Обновить политику конфиденциальности: AI-запросы и личный API-ключ проходят через proxy к Tooken

**Не начинать upload (4.3), пока 4.0 не проверен на развёрнутом worker.**
