# Spec: Цветные селекторы перечислений

## Objective

Заменить chip-кнопки в формах добавления снаряжения, создания квеста и добавления товара на селекторы в стиле выбора «Атмосфера контента» в настройках AI: кнопка с текущим значением открывает модальный список вариантов.

Редкость, состояние и сложность показывают эмодзи, название и цветной контур состояния. Текст остаётся интерфейсным. Игровые значения, сохранение и обработчики форм не меняются.

Chip-кнопки сохраняются для слотов экипировки и типа квеста. Активный chip остаётся залитым зелёным.

## Tech Stack

- Vanilla HTML, CSS и JavaScript.
- Исходники: `index.html`, `css/components.css`, `js/enum-picker.js`, `js/init-pickers.js`.
- Синхронизация web/Android: `npm run prepare:web`.
- Тесты: Node.js `assert` и `vm`.

## Commands

```powershell
npm run prepare:web
node tests/enum-picker.test.js
node tests/settings-ui.test.js
node tests/html-structure.test.js
npm run test:all
```

## Selection Contract

### Modal selectors

- Экипировка, редкость: ⚪ Обычная, 🟢 Необычная, 🔵 Редкая, 🟣 Эпическая, 🟡 Легендарная, 🟠 Уникальная, 🔴 Мифическая.
- Экипировка, состояние: 🔴 Сломанное, 🟠 Повреждённое, 🟡 Потрёпанное, 🟢 Хорошее, 🔵 Надёжное, 🔷 Отличное, 🟣 Идеальное.
- Квесты, сложность: ⚪ Новичок, 🟢 Ученик, 🔵 Адепт, 🟣 Эксперт, 🟡 Мастер.
- Магазин, редкость: те же семь значений редкости.

Цвет контура соответствует эмодзи. Modal использует нативные `button`, `role="dialog"`, `aria-modal`, `aria-pressed`, кнопку закрытия, закрытие по overlay и фокус на кнопке закрытия.

### Preserved chips

- Слот экипировки остаётся chip-picker с группами слотов.
- Тип квеста остаётся двумя chip-кнопками «Обычный» и «Рейд».
- Активный chip остаётся зелёным с заливкой.

## Testing Strategy

- Unit/DOM-тесты проверяют открытие modal, варианты, цветовые классы, `aria-pressed`, обновление hidden input, bubbling `change` и закрытие.
- Регрессионные проверки: `settings-ui`, `html-structure`, Capacitor, mobile и offline tests.
- UI проверен в браузере на desktop и ширине 320 px.
- После изменений выполняется `npm run prepare:web`; generated-копии не редактируются вручную.

## Boundaries

- **Always:** сохранять существующие ID и значения hidden-полей; отправлять bubbling `change`; сохранять доступность и mobile layout; запускать focused tests.
- **Ask first:** изменения схемы сохранений, логики форм, зависимостей, CI или Capacitor-конфигурации.
- **Never:** менять семантику игровых значений; превращать слоты или тип квеста в modal; удалять тесты; перезаписывать несвязанные изменения пользователя.

## Success Criteria

1. Редкость, состояние и сложность выбираются modal-списками.
2. Каждый вариант показывает требуемые эмодзи, название и цветной контур.
3. Текст остаётся интерфейсного цвета.
4. Слоты и тип квеста остаются зелёными chip-кнопками.
5. Hidden-поля и существующая логика форм продолжают работать.
6. Modal доступен с клавиатуры и корректно закрывается.
7. `www/` и Android public assets синхронизированы через `npm run prepare:web`.
